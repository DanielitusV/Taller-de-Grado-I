\section{Definición de términos}

\begin{itemize}
    \item \textbf{Ciberseguridad:} conjunto de prácticas orientadas a proteger sistemas, redes, dispositivos e información frente a amenazas digitales.
    \item \textbf{Amenaza digital:} evento o acción que puede comprometer la confidencialidad, integridad o disponibilidad de un sistema.
    \item \textbf{Vulnerabilidad:} debilidad técnica, humana u organizacional que puede ser aprovechada por una amenaza.
    \item \textbf{Gamificación:} uso de elementos de juego en contextos no lúdicos con fines de motivación y apoyo al aprendizaje.
    \item \textbf{Juego serio:} aplicación interactiva diseñada principalmente para enseñar, entrenar o concientizar.
    \item \textbf{Retroalimentación inmediata:} respuesta que recibe el usuario después de una acción, indicando aciertos, errores o consecuencias.
\end{itemize}
